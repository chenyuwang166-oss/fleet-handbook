# 审批流：事项与谁定

由读者按项目填写并确认；表中的分工是起草建议，不自动生效。

| 事项 | 谁定 |
|---|---|
| 已给授权内的实现细节与修复 | 执行成员 |
| 部门内的质量与方法 | 部门负责人；未设时由项目经理 |
| 项目内的先后次序、跨组协调与验收安排 | 项目经理 |
| 花钱与授权范围 | 人；已有授权内按约定执行 |
| 账号凭据及需要本人操作的动作 | 人 |
| 对外发出与公开承诺 | 人 |
| 不可撤回的删除 | 人 |
| 项目目标和方向 | 人 |
| 既定方向内的岗位分工和工作规矩 | 填写对这类改动有决定权的岗位及其授权范围 |
| 例行进展知会 | 项目经理汇总，知会不等于审批 |
